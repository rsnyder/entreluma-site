Interactive storytelling with Markdown

Entreluma helps you weave words, images, maps, video, and sources into stories readers can explore. Publish a static website on GitHub Pages, with your content in a repository you control.

Create your site · Get started · Explore an example

Connect the story to the details

Let readers zoom into an image, follow a place on a map, compare two views, or jump to a moment in a video. Links in your prose can guide these viewers, keeping the evidence close to the narrative.

A publishing workflow you can make your own

Write in Markdown, keep your media alongside your stories, and publish through GitHub Actions. Entreluma adds interactive viewers to the Chirpy Jekyll theme. Use it for visual essays, place-based stories, teaching materials, and research narratives.

An optional browser editor

The Entreluma Editor offers Markdown editing, live preview, local story packages, and GitHub sync. You can also use a text editor or GitHub’s web interface; the publishing template works independently of the editor.
