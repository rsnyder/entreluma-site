Interactive storytelling with Markdown

Connect the story to the details.

Entreluma is a free, open-source framework for weaving words, images, maps, video, and sources into stories readers can explore. It favors simple, durable publishing and keeps the content in a project you control.

Get started

Look closer

Guide readers to a revealing detail inside an image or compare two views.

Follow the place

Move a map with the narrative and connect people, events, and locations.

Keep media in context

Cue video and linked sources at the moment they matter to the story.

Stories with something to explore

Built for subjects that benefit from context.

Entreluma is useful when readers need to move between an explanation and the evidence behind it—not just scroll past a gallery of media.

Collections and exhibits

Interpret artworks, photographs, documents, and artifacts while keeping the object close to the narrative.

Places and journeys

Connect a story to locations, routes, and changing viewpoints without separating the map from the reading experience.

Research and teaching

Bring sources, observations, and media together in an explorable account that can be shared on the open web.

Small by design

Simple infrastructure. Stories made to last.

Entreluma follows a minimal computing philosophy: use open formats, keep the technical footprint small, and add complexity only when it serves the story.

Free and open source

Use, study, adapt, and extend the framework without a license fee or a proprietary publishing platform.

Ready in five minutes

Create a working site in about five minutes, then shape it gradually around your subject and audience.

Fewer moving parts

Static publishing needs no database or always-on application, making a site easier to maintain, move, and preserve.

Extensible when needed

Start with the included viewers and layouts, then add ordinary web technologies as the project grows.

Mobile friendly from the start

Responsive layouts adapt the story, navigation, and interactive viewers for phones, tablets, and larger screens.

A familiar publishing workflow

A simple path from draft to site.

Work in any text editor, or use the optional Entreluma Editor for a live preview as you build the story.

  1. 1

    Write

    Start with Markdown so the words remain readable, portable, and easy to revise.

  2. 2

    Enrich

    Add an image, map, comparison, video, or source where it helps the reader understand. Each interactive viewer takes a single, simple include tag placed directly in the Markdown—describe what to show, and Entreluma handles the presentation.

  3. 3

    Publish

    Turn the story into a website you can share, while keeping the content in your own project.
